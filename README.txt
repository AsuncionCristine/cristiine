SETUP
1. Start Apache in XAMPP (MySQL is only needed for the contact form messages).
2. phpMyAdmin > Import > choose database.sql > Import.
3. Put this folder in XAMPP's htdocs folder.
4. Save your photo as assets/photo.jpg
   Family pictures: assets/family1.jpg and assets/family2.jpg
5. Open http://localhost/cristine/

EDIT YOUR TEXT IN THE CODE of each page (no database for content):
- includes/header.php : your name and Facebook/Instagram/Telegram links
- index.php      : role, tagline and your quotes in life
- about.php      : about boxes and the family photo buttons
- skills.php     : skills
- education.php  : schools
- contact.php    : phone and email
The database only saves messages from the contact form.
